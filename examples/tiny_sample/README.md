# Tiny Sample

这是一个极小的合成样例，只用于验证代码读取流程、路径约定和字段格式，不代表完整实验数据，也不能用于报告实验结果。

样例文件遵循 processed 数据格式：

- `train.tsv`
- `dev.tsv`
- `test.tsv`
- `seqrec_sequence.txt`
- `seqrec_interactions.txt`
- `user2id.json`
- `id2user.json`
- `item2id.json`
- `id2item.json`
- `stats.json`

完整数据应放在本地 `data/raw/` 和 `data/processed/`，不上传 GitHub。
